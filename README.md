## 📖 Sobre o projeto

O **Projeto Playlist** é um site com playlists musicais organizadas por artista. Na página inicial, o usuário escolhe um artista e acessa a página com a playlist dele.

## 🎤 Artistas

| # | Artista | Estilos | Página |
|---|---------|---------|--------|
| 01 | **Lady Gaga** | Pop • Dance • Eletrônico | [gaga.html](https://marciomojr.github.io/Projeto-Playlist/gaga.html) |
| 02 | **Bruno Mars** | Pop • R&B • Soul | [bruno.html](https://marciomojr.github.io/Projeto-Playlist/bruno.html) |
| 03 | **The Weeknd** | Pop • R&B • Soul | [weeknd.html](https://marciomojr.github.io/Projeto-Playlist/weeknd.html) |

## 🛠️ Tecnologias

- **HTML5** – estrutura das páginas
- **CSS3** – estilização e layout
- **GitHub Pages** e **Vercel** – publicação do site

## 📁 Estrutura do projeto

```
Projeto-Playlist/
├── CSS/            # Folhas de estilo
├── audio/          # Arquivos de áudio
├── img/            # Imagens
├── index.html      # Página inicial
├── gaga.html       # Playlist da Lady Gaga
├── bruno.html      # Playlist do Bruno Mars
└── weeknd.html     # Playlist do The Weeknd
```

## 🚀 Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/MarcioMoJr/Projeto-Playlist.git
```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Ou, se preferir, acesse direto pelo site: [Projeto Playlist](https://projeto-playlist-six.vercel.app/)
